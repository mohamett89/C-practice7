# C# Full Date Windows Forms Project

## 📌 Project Overview

This project is a simple **C# Windows Forms** application that builds and displays a complete date by combining:

- Day of the week
- Name of the month
- Numeric day
- Year

The project also includes **Clear** and **Close** buttons.


## 📅 Full Date Concatenation

The application combines the date values using the `+` operator.

Fulldate = day_of_the_week + ", " + Name_of_the_month + ", " + NumericDay + ", " + Year;
